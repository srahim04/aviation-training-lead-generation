# AeroPath Training – Website Demo

[**Watch My Website Demo**](https://github.com/srahim04/aviation-training-lead-generation/releases/tag/v1.0)

I put together a short walkthrough of the AeroPath Training website to show how everything works.

In the video, I go through the training programs, show how the inquiry form works, and demonstrate how the website adjusts to mobile screens. I also explain why I added a sticky navigation bar so visitors can move between sections without scrolling back to the top.

I briefly talk about the performance improvements I made and how I used Google Tag Manager to test website interactions.

I've also included screenshots of the website, Google Tag Manager testing, and my Lighthouse results in the [`screenshots`](../screenshots/) folder.
